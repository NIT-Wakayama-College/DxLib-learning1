### **(1) キャラクターを操作したい！**
#### **(どうすればいいか？)**
- `Player` クラスを作成し、位置情報と描画処理を分離する。
- `Update()` メソッドを持たせて、キー入力で移動できるようにする。
- `Render()` メソッドで、画面上に表示します。

#### **(変更後のソースコード)**
```cs:Player.cs
class Player {
    const int SPEED = 3;
    const int SIZE = 32;

    Vector2 _position;

    public Player() {
        _position = new Vector2(100f, 100f);
    }

    public void Update(InputState input) {
        if (input.Up) _position.Y -= SPEED;
        if (input.Down) _position.Y += SPEED;
        if (input.Left) _position.X -= SPEED;
        if (input.Right) _position.X += SPEED;
    }

    public void Render() {
        Program.DrawBox(PlayerX, PlayerY, SIZE, SIZE, Program.COLOR_WHITE); // プレイヤーを描画
    }
}
```

#### **(ポイント)**
✅ `Player` クラスを作ったことで、キャラクターの管理が簡単になった！  
✅ `Update()` で移動を制御し、ゲーム全体のロジックと分離できた！

# 地面との接地判定

次に、プレイヤーが地面に接しているかを判定するメソッドを追加します。
```cs:Player.cs
internal class Player
{
	private bool IsGround() {
        // y座標が地面以上であれば接地している
		return _y >= 300;
	}
}
```

### 解説
- `IsGround` **メソッド**：プレイヤーのy座標が地面の高さ以上の場合に `true` を返します。これを使ってジャンプ可能かどうかを判断します


# 簡易的なジャンプと重力処理

プレイヤーがジャンプし、重力によって自然に下に落ちる動作を追加します。

```cs:Player.cs
internal class Player
{
	public void Update() {
		if (DX.GetMouseInput() == DX.MOUSE_INPUT_LEFT && IsGround()) {
            // ジャンプ処理
			_y -= 10;
		}

        // 重力処理
		if (!IsGround()) _y++;
	}
}
```

### 解説
- **ジャンプ処理**：左クリック（ `DX.MOUSE_INPUT_LEFT` ）が入力され、プレイヤーが地面に接している場合にジャンプします
- **重力処理**：地面に接していない間、プレイヤーが徐々に下に落ちる動作を再現します


# 現実的なジャンプ処理

最後に、重力を加速的に変化させ、現実的なジャンプを実現します。

```cs:Player.cs
internal class Player
{
    // 重力の値
	private int _gravity = 0;

    public void Update() {
    	if (!IsGround()) {
    		_gravity += 1; // 重力による加速
    	} else {
    		_y = 300; // 地面に戻る
    		_gravity = 0; // 重力リセット
    	}
     
    	if (DX.GetMouseInput() == DX.MOUSE_INPUT_LEFT && IsGround()) {
    		_gravity = -10; // ジャンプ時の初速を設定
    	}
    
    	_y += _gravity; // 現在の重力を適用
    }
}
```

### 解説
- **ジャンプ初速の設定**：左クリックでジャンプした際に、負の重力（上方向の加速）を設定します
- **重力の加速**：地面に接していない場合、重力が徐々に増加し、下方向の速度が速くなります
- **接地時の処理**：地面に到達したらy座標をリセットし、重力を0に戻します

# Gameクラスから呼び出す

最後に、`Program.cs` の `Game` クラスから `Player` クラスの `Load` , `Draw` および `Update` 関数を呼び出します。

以下が `Game` クラスの変更点です。

```cs:Program.cs
internal class Game
{
	private Player _player;

	public Game() {
		_player = new Player();
	}

	public void Load() {
		// 画像の読み込み
        _player.Load();
	}

	private void Loop() {
		// メインループ
		while (DX.ProcessMessage() == 0) {
            // 更新処理
			Update();
			// 画像を描画
			Draw();
		}
	}

    private void Update() {
		// プレイヤーの更新
		_player.Update();
	}

	private void Draw() {
		// 画面をクリア
		DX.ClearDrawScreen();

        // プレイヤーを描画
		_player.Draw();

		// 裏画面の内容を表画面に反映
		DX.ScreenFlip();
	}
}
```
