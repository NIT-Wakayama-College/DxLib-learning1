## **ステップ 1: こうしたい！**  
キャラクターの移動にジャンプと重力の要素を追加し、より自然な動きを実現したい。  

1. **ジャンプの追加**  
   → プレイヤーがジャンプボタンを押すと、上方向に移動する動きを実装する。  

2. **重力の追加**  
   → ジャンプ後に自然に落下するよう、時間経過で下降する処理を組み込む。  

3. **地面での停止処理**  
   → キャラクターが地面に到達したら停止し、それ以上沈まないようにする。  

---

## **ステップ 2: 変更点ごとの詳細解説**  

### **(1) ジャンプの追加**  
#### **(どうすればいいか？)**  
- `_gravity` 変数を導入し、ジャンプ時に `JUMP_FORCE` を代入する。  
- `input.Jump` を検知し、地面にいるときだけジャンプ可能にする。  

#### **(変更後のソースコード)**  
```csharp
void HandleInput(InputState input) {
    if (input.Left) _playerX -= SPEED;
    if (input.Right) _playerX += SPEED;

    if (input.Jump && _playerY == 300) _gravity = JUMP_FORCE;
}
```

#### **(ポイント)**  
✅ `_gravity` に負の値をセットすることで、上方向の移動を表現  
✅ 地面にいるときのみジャンプ可能にすることで、多段ジャンプを防止  

---

### **(2) 重力の追加**  
#### **(どうすればいいか？)**  
- `_gravity` をフレームごとに増加させ、自然な落下を表現する。  
- `_playerY` に `_gravity` の値を加算し、キャラクターの位置を更新する。  

#### **(変更後のソースコード)**  
```csharp
void ApplyGravity() {
    _playerY += _gravity;
    _gravity += GRAVITY_INCREMENT;
}
```

#### **(ポイント)**  
✅ フレームごとに `_gravity` を増加させることで、落下スピードを徐々に加速  
✅ `_playerY` に `_gravity` を適用することで、重力による移動を表現  

---

### **(3) 地面での停止処理**  
#### **(どうすればいいか？)**  
- `_playerY` が地面 (`Game.GROUND_Y`) を超えたら、位置を固定し `_gravity` をリセットする。  

#### **(変更後のソースコード)**  
```csharp
if (_playerY > Game.GROUND_Y) {
    _playerY = Game.GROUND_Y;
    _gravity = 0;
}
```

#### **(ポイント)**  
✅ `_playerY` を `Game.GROUND_Y` に固定することで、地面にめり込むのを防ぐ  
✅ `_gravity` を 0 にリセットし、次のジャンプが正常に動作するようにする
